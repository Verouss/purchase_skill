## 📖 简介

一个面向 AI 助手的采购选品知识库，提供从品类规划到供应商管理、从成本分析到可持续采购的**全链路方法论指导**。不是简单问答，而是可复现的决策框架。

```
品类规划 → 供应商评估 → 商品力评估 → 成本分析 → 采购策略
    → 招标合规 → SRM 关系管理 → 需求预测 → 可持续采购 → 绩效考核
```

## 📊 使用示例

### 示例 1：新品选品决策

> **用户：** "我们想在生鲜电商平台上新增冷藏乳品品类，该怎么选品？"

**Skill 输出流程：**

```
① 品类定位 → 常规性品类（高频刚需）
② 市场扫描 → 植物基年增 30%，当日达是差异突破口
③ 供应商寻源 → 全国大牌（竞价）+ 区域乳企（差异化）+ 本地牧场（独家）
④ 商品力评估 → KVI 品（鲜牛奶/原味酸奶）+ 利润品（希腊酸奶毛利 45%+）+ 引流品
⑤ 成本分析 → 原奶+加工+包材+冷链四要素拆解，三家 TCO 对比
⑥ 库存计划 → AX 类，SS=59 瓶，ROP=259 瓶，服务水平 97.5%
⑦ 输出 → 完整品类选品规划书
```

### 示例 2：供应商评估体系建设

> **用户：** "我们公司要建立一套供应商评估体系，该怎么做？"

**Skill 输出流程：**

```
① 按 Kraljic 矩阵对采购品类分层
② 四类品类配置不同 QCDS 权重（战略品重质量、杠杆品重成本）
③ 设计寻源漏斗（市场扫描→RFI→RFP→现场审核→签约）
④ 建立 A/B/C/D 四级供应商分级标准
⑤ 配置红黄绿灯预警和退出机制
⑥ 输出完整的供应商评估体系框架
```

## 🧠 设计理念

| 原则 | 说明 |
|------|------|
| **先诊断，后开方** | 生鲜的逻辑和 3C 完全相反。每次给出建议前，先确认用户的行业、品类、业务阶段 |
| **方法论优先，案例配套** | 先讲清楚框架和判断逻辑，再给案例——用户需要可复用的思考工具，不是一次性答案 |
| **定量与定性结合** | 能公式化的给出公式（安全库存、EOQ、毛利率底线），无法量化的给出决策树 |
| **风险意识贯穿** | 每个决策环节主动提示关键风险及失效条件。采购决策的损失通常是不可逆的 |
| **按需深入** | 从 SKILL.md 的快速参考开始，用户追问时才打开参考文件。避免一次性信息轰炸 |
